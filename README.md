## 安装

### 作为 Agent Skill

把本仓库放到 AI Agent 的 skills 目录即可，保持目录结构：

```bash
git clone https://github.com/16512354554/circuit-repair-skill.git
cp -r circuit-repair-skill ~/.claude/skills/circuit-repair   # 以 Claude Code 为例
```

要求：`SKILL.md` 在技能目录根部，`references/` 与其同级。

### 人工使用

直接打开 `references/` 下对应卡片，按决策树/表格查参数、判据与步骤。

## 使用示例

- 「电动车充电器无输出，大电解有 310V，怎么查？」
- 「BGA 芯片虚焊，重植锡的温度和步骤是什么？」
- 「这块板没有图纸，开机电流只有 50mA，从哪里入手？」
- 「UC3842 的 7 脚只有 8V，是不是芯片坏了？」
- 「想从零学电路维修，先学什么、买什么工具？」

## 设计原则

1. **安全优先**：任何带电测量先给安全前置，热地/大电解/隔离红线不可跳过。
2. **可执行**：给「先查什么 → 怎么测 → 判据 → 下一步」，而不是泛泛的原理。
3. **数值带条件**：温度、电流、电压等经验值保留设备与工艺前提。
4. **区分层级**：现场经验、通用工程知识、器件手册数据分开标注。
5. **敢标存疑**：说法与工程逻辑冲突时标「存疑」并给正确判据。
