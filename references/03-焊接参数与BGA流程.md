# 03 焊接参数与 BGA 流程

> 用途：查温度、风速、步骤，照着做。
> 铁律：风枪「设定温度」不等于「焊点温度」，送热效率取决于风口距离、风量、遮挡与焊盘散热。
> 内容：整理自一线硬件工程师的焊接返修经验与通用工艺规范。

## 1. 三个温度概念

| 概念 | 说明 |
|---|---|
| 设定温度 | 风枪/烙铁旋钮显示值 |
| 焊点温度 | 实际到达焊点的温度，通常低于设定值 |
| 熔点 | 焊料由固态变液态的温度 |

判断：400~500℃ 仍不熔锡 = 热没送到焊点（风口远、风量小、被遮挡、焊盘散热大），不要一味加温。

## 2. 焊料与助焊剂

| 焊料 | 熔点 | 适用 |
|---|---|---|
| 有铅 Sn63Pb37 | 183℃ | 家电、工控、拆芯片、补焊（低热冲击） |
| 无铅 | 217~227℃ | 原厂无铅板；比有铅高 30~40℃，焊点暗、易虚焊 |
| 低温锡浆 | 138~150℃ | 不耐高温的板/件 |
| 中温锡浆 | 183℃ | BGA 植锡常用 |

助焊油两作用：①清除氧化、助润湿；②隔热、保护塑料件。
原则：焊 LED、内联座宁多勿少；密脚器件必须用焊油，只用松香易连锡、虚焊。

## 3. 温度/风速参数总表

| 对象 | 温度 | 风速/风档 | 备注 |
|---|---|---|---|
| 通用热风枪 | 320~350℃ | 1~3 档 | 不超过 370℃ |
| BGA 拆片 | 350℃左右 | 50~60% | 大风嘴 |
| BGA 植锡 | 310℃±10℃ | 40~50% | 风口倾斜紧贴植锡网 |
| BGA 装回 | 320℃±5℃ | 40~50% | 风口距 1~2cm |
| 大体积 BGA 预热 | 180℃ | — | 约 40 秒；小 BGA 免预热 |
| 拆芯片（原厂高温锡） | 330~350℃ | 45°画圈 | 均匀受热 |
| 射频 IC 拆 | 270~350℃ | 5 档 | — |
| 射频 IC 植锡 | 320℃ | — | — |
| 装射频 IC | 250~270℃ | 50~70% | 180℃预热 1~2 分，再 60~90 秒 |
| 内联座拆 | 320~350℃（≤370℃） | 1~3 档 | 距 1~1.5cm，45°画圈 |
| 内联座装 | 320℃ | 最小风量 | 或 250~300℃恒温画圈 |
| 金属卡扣触点 | 280~340℃ | 3~4 档 | 不同品牌有差异 |
| 焊盘盘圈修复 | 320~350℃（≤370℃） | 1~3 档 | 858D 风枪 |

磁吸提示：直风枪热量集中，适合小焊盘/连接器；旋风枪柔和均匀，适合大芯片与塑料件周边。

## 4. SMD 贴片焊接流程

1. 焊盘涂焊油
2. 对位（丝印/极性点）
3. 先固定一端
4. 焊另一端
5. 补锡成弧形
6. 洗板水清洗、放大镜检查

要点：
- 0402/0201 用卡尺（约 5 元）量尺寸对封装表。
- 贴片 LED：圆形丝印点/本体绿色标记 = 阴极，焊后加电试亮。
- SOT-23：先固定一脚再焊其余。
- 8 脚 IC：缺口对 1 脚，逐脚点焊、锡量少。
- 散热焊盘 = PCB 上最大铜箔，先镀薄锡让锡渗到芯片底部，否则换上又烧。
- 100 脚 QFP：左下小圆点 = 1 脚；敏感芯片禁止烙铁长时间拖锡/风枪大面积吹，只能逐脚焊。

## 5. BGA 六步流程

| 步骤 | 操作 | 关键点 |
|---|---|---|
| ① 拍照标记 | 拍芯片方向、四周元件 | 防装反、防丢件 |
| ② 固定板 | 夹具/高温胶带固定 | 防移位 |
| ③ 预热拆片 | 大风嘴 350℃左右、风速 50~60% | 大 BGA 先 180℃预热约 40 秒 |
| ④ 清焊盘 | 吸锡带拖平、清洗 | 不掉点、不留残锡 |
| ⑤ 植锡 | 中温锡浆 + 植锡网，310℃±10℃、40~50% | 风口倾斜紧贴网，锡球均匀 |
| ⑥ 装回 | 对位，320℃±5℃、40~50%，距 1~2cm | 冷却后轻推验证 |

BGA 虚焊典型症状：耗电快 + 机身发热 + 无规律死机。
拆焊温度过高 → 掉点、变形；拆前必须确认焊盘状态与客户风险。

## 6. 内联座（FPC/连接器）拆装

### 6.1 拆卸

1. 高温胶带保护周边塑料件
2. 圆形小口径风嘴，距 1~1.5cm，45°画圈
3. 320~350℃、风档 1~3，最多不超过 370℃
4. 焊锡全熔后轻取，禁止硬撬
5. 掉点先补点，再装新座

### 6.2 安装

1. 每个焊盘上薄锡
2. 对位（座子方向、引脚对齐）
3. 320℃ 最小风量画圈；或焊油多打 + 先低温预热，逐步升到 250~300℃ 恒温画圈
4. 座子微下沉、贴平即停风
5. 冷却后逐脚补锡
6. 蜂鸣档逐点测通断

要点：成败 90% 在温度与焊油；塑料座子吹熔/变形不可逆。

## 7. USB 尾插更换 5 步

1. 断电
2. 加焊油，风枪化锡取旧（氧化多加焊油）
3. 拖平焊盘，氧化处镀薄锡
4. 新尾插先固定两边接地脚
5. 少许锡浆、风枪加热（温度风速不宜过大）
6. 洗板水 + 放大镜检查
7. 上电测试

## 8. FPC/FFC 与软排线

修复链条：固定 → 刮绿油露铜 → 上锡 → 飞线 → 绝缘封层。
- 0.01mm 间距软排线也可手工修复。
- 排线断裂：对齐、固定、逐线飞线，UV 绿油封层。
- FFC 连接座：老旧板优先用烙铁拆，热风枪易吹坏塑料。
- FPC 上小元件：用烙铁快速拆装，FPC 不耐高温。
- 轻触开关：温度不能太高，否则内部受损。
- 宽脚器件：一次到位，不反复烘烤。

## 9. 焊盘掉点与断线修复

### 9.1 盘圈法（BGA 焊盘掉点）

1. 刮开阻焊，找到同网络铜箔/走线
2. 超细漆包线一端焊在走线上
3. 另一端绕成与原焊盘同尺寸圆环
4. 镀锡、修平
5. 涂绿油、UV 固化
6. 蜂鸣档测通断

工具：超细漆包线、显微镜、恒温烙铁、低温焊锡、助焊油、绿油 + UV、洗板水、3# 手术刀片 + 11 号手柄、858D 风枪。

### 9.2 其他三法

| 方法 | 适用 |
|---|---|
| 补点焊片法 | 免打圈，直接补焊片 |
| 挖孔法 | 内层走线腐蚀/烧断，逐层挖到内层铜箔 |
| 夹层断线搭桥 | 点位图定位→分层挖孔→内层飞线→洗板→UV 封层→固化→复测 |

### 9.3 八条硬约束

1. 轻刮慢磨，不伤相邻线路
2. 线径细、圆环大小与高度与原焊盘一致
3. 烙铁温度不高、快速点焊
4. 焊点牢固，轻拉不脱
5. 绿油涂满并完全固化
6. 显微镜下操作
7. 每个点必须测通断
8. 装芯片前复测，防顶起

## 10. UV 固化与清洗

- UV 灯 10W 及以上，照 3~30 秒完全固化。
- 验钞灯需 5 分钟。
- 洗板水清洗后用放大镜检查残锡、连锡、绿油覆盖。

## 11. 禁忌清单

- 拆焊温度过高 → BGA/内联座掉点、变形
- 塑料件不用焊油隔热
- 飞线堆锡 → 顶起芯片
- 绿油不固化就装机
- 修完不测通断
- 密脚只用松香
- 把设定温度当焊点温度
- 进水板未清洗干燥就上电

## 12. 焊接质量验收

| 项目 | 合格标准 |
|---|---|
| 焊点外观 | 光亮、弧形、吃锡饱满，无拉尖 |
| 连锡 | 密脚间无桥接，放大镜复查 |
| 虚焊 | 轻推不晃，引脚与焊盘完全润湿 |
| 掉点 | 补点牢固，蜂鸣档通断正常 |
| 绿油 | 覆盖完整、固化不发黏 |
| 座子 | 贴平、不歪斜、不微浮 |
| 整机 | 上电电流正常，带载 10 分钟复测 |
| 记录 | 拍照留档：拆前、补点、装回 |

补充：有铅焊点偏亮、无铅偏暗属正常；不要用外观亮度判断无铅焊点好坏。


> 温度与风速是区间不是定值：同一参数在不同风枪、风口、板厚上要微调，先做废板试焊。
