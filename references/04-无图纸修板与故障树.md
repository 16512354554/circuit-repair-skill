# 04 无图纸修板与故障树

> 用途：没有图纸、没有点位图，也能把陌生板拆成「区块」逐个排除。
> 核心思路：先分区、后测电、再顺故障树走；不跨安全隔离带乱测。
> 内容：整理自一线硬件工程师的无图纸修板与故障树诊断经验。

## 1. 七步法：把陌生板读成地图

| 步 | 看什么 | 目的 |
|---|---|---|
| ① 观察物理结构 | 螺丝孔、插座、金手指、插槽、外形 | 判断设备类型与装配关系 |
| ② 找强弱电隔离带 | 空白隔断区：强电侧保险/压敏/安规电容/电感，弱电侧低压小件 | 国标安全红线，分区测量 |
| ③ 找电源供电区 | 大电解、功率电感、MOS、DCDC、LDO | 故障率最高，最先查 |
| ④ 找接口保护区 | 电源口、USB、网口、卡槽旁的 ESD/TVS、共模电感 | 接口→保护→核心 |
| ⑤ 找核心主控区 | 最大主芯片（CPU/MCU/FPGA），最干净位置，旁有晶振 + 去耦小贴片 | 定位主控及其时钟 |
| ⑥ 拆外设功能区 | 电机驱动、传感器、音频、存储、IO | 按功能定位 |
| ⑦ 散热与辅助 | 大功率器件、散热片、裸露测试点、丝印 | 找热源与测试点 |

要点：强电侧元件个头大、间距宽；弱电侧元件小、密度高。测试点（TP）和丝印是免费图纸。

## 2. 三条判断依据

1. 强弱电必须分开：不跨隔离带测，防止炸表、触电、二次损坏。
2. 供电是命脉：先查「通不通、稳不稳、温度高不高」。
3. 高精度设备对电源更敏感：纹波、电压偏差、地线干扰都可能引发怪故障。

## 3. 开机电流法（板级最快入口）

### 3.1 上电时序

```
电池/适配器 → PMIC → 多级供电（一级/二级/三级）
→ CPU 上电 + 时钟起振 → I2C/SPI 读取存储 → 外设初始化
```

适用：手机、无人机、数码相机、对讲机、PAD、笔记本、小型 PLC、HMI、工控触摸屏、扫地机器人。

### 3.2 四态分流

| 电流表现 | 故障范围 | 处理 |
|---|---|---|
| 未开机就大电流 | 前级输入、充电 IC 一级供电短路 | 松香法/烧机法；低电压限流 |
| 按开机键瞬间大电流 | PMIC 输出端某路主供电负载短路 | 逐路断开，测大电容、大电感 |
| 按开机键无电流 | 开关/输入级未通 | 测按键通断、充电 IC 输入端电压 |
| 有电流但偏小 | 初始化未完成 | 测主时钟；查 CPU 虚焊、暂存器、自控芯片、存储 |

注意：保护电路可能让大电流只出现一瞬间；不要长时间硬烧，以免扩大故障。

### 3.3 找短路

1. 优先测大电容、大电感（低阻节点）
2. 优先测主供电引脚（PMIC 各路输出）
3. 从低电压、限流起，逐级加压
4. 配合松香法（发热点冒烟/变亮）或热成像
5. 分段断开：拆电感/跳线，缩小短路范围

## 4. 三要素：供电 → 复位 → 时钟

| 顺序 | 测什么 | 异常结论 |
|---|---|---|
| ① 供电 | VCC/各路 LDO、DCDC 输出 | 为 0/偏低：前级缺失、保护动作、滤波电容击穿短路 |
| ② 复位 | RST 脚有无跳变 | 无跳变：复位电路或主控未启动 |
| ③ 时钟 | 晶振/时钟脚波形 | 无时钟：晶振、负载电容、主控 |

边界：三要素只能证明「基本工作条件」，不能证明程序、逻辑、通信是否正常。
工具分工：万用表判断「有没有」，示波器判断「对不对」（时钟波形、供电纹波、复位时序、通信波形）。

## 5. 故障树（照树排查）

```
故障现象
├─ 未开机就大电流
│   └→ 前级输入短路 → 充电 IC 一级供电/输入保护
│       └→ 松香法/烧机法定位发热件
├─ 按开机键瞬间大电流
│   └→ PMIC 输出端负载短路
│       └→ 分段断开，测大电容大电感
├─ 按开机键无电流
│   └→ 按键失效 / 充电 IC 输入端及外围
├─ 有电流但偏小
│   ├→ 三要素逐项
│   ├→ 主时钟不起振 → 晶振/负载电容/主控
│   └→ 三要素正常 → CPU 虚焊/暂存器/存储 → 重植锡/换件
├─ 能开机但功能异常
│   ├→ 单一功能：查对应外设区
│   ├→ 多模块异常：回公共资源（供电纹波/主控/总线）
│   └→ 接口异常：先查保护器件（ESD/TVS/共模电感）
└─ 进水/腐蚀
    └→ 先清洗干燥，再按上面分支
```

## 6. 进水机处理（先保命再保板）

### 6.1 六个绝对禁止

1. 通电、开机、充电、插数据线
2. 热风、烤箱、暖气烘烤
3. 甩动（水扩散）
4. 大米（粉尘+潮气）
5. 淡水机直接冲；海水/自来水冲完放着
6. 鼓包电池继续操作

### 6.2 标准流程

1. 断电、拆电池
2. 清表面杂质；海水机用充分淡水冲盐
3. 阴凉通风沥干（禁热风、禁大米）
4. 无水乙醇清洁
5. 尽快拆机深度清洗检测
6. 不要「晾干就上电」

### 6.3 板级修复顺序

清洁 → 刮线 → 拖锡连通 → 清溢锡分隔 → 涂 UV 绿油 → 紫外固化 → 洗板复测。

## 7. 记录与复测

| 阶段 | 必做 |
|---|---|
| 接修 | 记录现象、客户描述、外观照片 |
| 拆机 | 拍照标记排线、螺丝位置 |
| 测量 | 记录电压/电流/阻值，写清档位 |
| 更换 | 记录型号、位置、方向 |
| 装机前 | 蜂鸣档逐点复测、外观检查 |
| 交付 | 带载测试 10 分钟、说明风险与保修 |

## 8. 常见错误

- 不分区就乱测，跨隔离带炸表
- 只看电压不看电流，短路点越烧越大
- 只测三要素就判芯片坏，忽略程序/通信
- 大电流硬烧，烧断铜箔、扩大故障
- 修完不测通断，装机再返工
- 进水机未干燥就上电

## 9. 各区块首查清单

| 区块 | 首查元件 | 快速判断 |
|---|---|---|
| 强电区 | 保险、压敏、整流桥、大电解、NTC | 蜂鸣档测短路，看鼓包 |
| 供电区 | 大电解、功率电感、MOS、DCDC、LDO | 测输入/输出/使能脚 |
| 接口保护区 | ESD/TVS、共模电感、限流电阻 | 测对地阻值，拆下复测 |
| 主控区 | 主芯片、晶振、去耦电容、复位脚 | 供电/复位/时钟三要素 |
| 外设区 | 驱动管、传感器、音频功放、存储 | 按功能逐个隔离 |
| 散热区 | 大功率器件、散热片、温度 | 摸温度、看硅脂、补焊 |

口诀：先电源、后接口、再主控、最后外设；先公共、后独有。

## 10. 无图纸时的三种替代资料

1. 丝印反查：读全丝印 → 量封装数引脚 → 平台反查 → 交叉验证。
2. 好板对照：同型号好板对比测阻值/电压，最快锁定异常点。
3. 点位图/图纸平台：鑫智造、蚂蚁昕、蓝瑞、维修宝典、ZXW、维修伴侣（详见 06 卡）。

注意：不同版本板子丝印与元件位号可能不同，以实物为准。

## 11. 万用表/示波器测点顺序

1. 蜂鸣档：保险、电感、0Ω、焊盘通断
2. 二极管档：二极管、三极管、MOS 体二极管
3. 直流电压档：310V、12V、5V、3.3V、VCC、基准
4. 频率档：PWM、时钟、通信
5. 示波器：纹波、复位时序、时钟波形、总线波形
6. 可调电源：限流烧机，观察电流变化

7. 热成像：找异常发热点，适合短路/漏电
8. 松香法：给怀疑区域涂松香酒精，通电看先熔化点
9. 对比法：同型号好板同点测阻值，差异大处即嫌疑
10. 断开法：拆电感/跳线分段，缩小故障范围

> 安全提醒：测热地必须单手、单点，脚不接地；不确定时先断电测阻值，再上电测电压。
