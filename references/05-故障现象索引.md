# 05 故障现象索引

> 用法：按「现象」查表 → 找到可能原因与案例 → 转 04 卡按故障树排查。
> 频次规律：不开机/死机/发热类，多数是供电、虚焊、进水；接口类多数是温度与焊油。
> 内容：整理自一线硬件工程师的大量实操维修案例与诊断经验。

## 1. 一分钟定位表

| 现象 | 首查 | 转卡片 |
|---|---|---|
| 完全不开机、无电流 | 按键、充电 IC 输入、前级供电 | 04·3.2 |
| 不开机、大电流 | 前级短路、PMIC 输出负载短路 | 04·3.2 |
| 开机但无显示 | 背光、显示座、屏排线 | 05·5 |
| 能开机、功能异常 | 对应外设区、接口保护 | 04·5 |
| 无规律死机/重启 | 虚焊、供电纹波、时钟 | 05·4 |
| 耗电快、机身发热 | BGA/CPU 虚焊、漏电 | 05·4 |
| 接口不识别/接触不良 | 内联座、USB 尾插、腐蚀 | 05·6 |
| 进水 | 先清洗干燥，禁止上电 | 04·6 |

## 2. 不开机 / 上电异常

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 按键不灵/按不动 | 轻触开关老化、内部受损 | 控温更换轻触开关 |
| 开机漏电、不上电 | 贴片电容击穿短路 | 查主供电滤波电容 |
| 通电不开机 | 芯片底部焊盘断线 | 底层飞线 |
| 插电无反应 | USB 尾插/接口坏 | 换尾插、补焊 |
| 开机后自动关 | 保护动作、供电不足 | 查过流/过压保护 |
| 换屏后不开机 | 排线座虚焊/装反 | 查内联座 |

## 3. 大电流 / 漏电 / 短路

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 未开机就大电流 | 前级输入短路 | 松香法/烧机法 |
| 按键瞬间大电流 | PMIC 输出负载短路 | 分段断开、测大电容大电感 |
| 待机漏电 | 射频 IC 软击穿、电容漏电 | 测各路电流、拆件对比 |
| 电容短路 | 贴片电容击穿 | 拆下测、替换 |
| 保险熔断 | 压敏/整流桥/开关管短路 | 先查短路链再换保险 |

## 4. 死机 / 重启 / 发热 / 耗电

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 无规律死机 | BGA/CPU 虚焊、射频 IC 虚焊 | 重植锡、补焊 |
| 耗电快 + 机身发热 | CPU 引脚虚焊、受潮氧化漏电 | 拆装重植锡 |
| 开机慢、卡画面 | 晶振/时钟异常、存储慢 | 测时钟、换晶振 |
| 反复重启 | 供电不稳、启动电容坏 | 查启动电路、滤波电容 |
| 热后死机 | 虚焊热胀冷缩 | 补焊/重植 |

## 5. 显示 / 触控异常

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 花屏、条纹 | 显示座虚焊、排线不良 | 补焊座子、换排线 |
| 无背光 | 背光升压、灯条 | 查 Boost 输出 |
| 触控间歇失灵 | 触控座、排线、时钟 | 查座子与时钟 |
| 按键乱跳 | 轻触开关、晶振 | 换开关、测时钟 |
| 屏闪/暗屏 | 供电纹波大、滤波电容坏 | 换滤波电容 |

## 6. 接口 / 排线 / 连接座

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 充电接触不良 | USB 尾插磨损/虚焊 | 换尾插 5 步 |
| 排线断裂 | 折伤、拉断 | 对齐飞线 + UV 封层 |
| 排线接口腐蚀 | 进水氧化 | 清洁、补线、换座 |
| 内联座虚焊/脱落 | 温度过高、受力 | 补点/换座 |
| 内联座吹熔变形 | 风温过高 | 控温 + 焊油 + 小风嘴 |
| FPC 排线坏 | 折伤、焊盘掉 | 修复 7 步 |
| FFC 座老化 | 塑料老化 | 烙铁拆装更稳 |
| 卡扣触点不良 | 氧化、磨损 | 280~340℃ 更换 |

## 7. 进水 / 腐蚀 / 断线

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 进水后不开机 | 腐蚀 + 通电扩大 | 清洗干燥再修 |
| 板层腐蚀断线 | 海水/长时间浸泡 | 刮线、拖锡、飞线 |
| 夹层内层断线 | 进水/大电流烧断 | 挖孔搭桥 |
| 过孔/焊盘掉点 | 拆焊温度过高 | 盘圈法/补点焊片 |
| 排线接口锈蚀 | 进水 | 清洁、换座 |
| 老相机泡水 | 长期淤泥封存 | 拆解清洗、耐心 |

## 8. BGA / 焊盘 / 虚焊

| 现象 | 可能原因 | 处理 |
|---|---|---|
| BGA 焊盘掉点 | 拆焊温度高/手法 | 盘圈补点、飞线 |
| BGA 断线 | 掉点连带断线 | 找底层走线重建 |
| BGA 虚焊 | 受潮、热循环 | 重植锡 |
| 芯片底部断线 | 焊盘脱层 | 底部飞线 |
| 补点后不通 | 圆环未接实、绿油未固化 | 复测通断、重做 |
| 装上又烧 | 散热焊盘未镀锡/虚焊 | 先镀锡再装 |

## 9. 芯片级 / 时钟 / 传感器

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 无时钟、不开机 | 晶振/负载电容/主控 | 测压差、代换晶振 |
| 蓝牙/WiFi/串口断续 | 时钟不稳、虚焊 | 查时钟、补焊 |
| 导航/罗盘失效 | 导航芯片坏 | 外置导航芯片替换 |
| 无规律死机 + 信号跳变 | 射频 IC 虚焊/并锡 | 测供电电流、重植 |
| 传感器无输出 | 霍尔/供电/地 | 测三脚电压 |
| 按键误触发 | 上拉/下拉缺失、悬空 | 补电阻、查虚焊 |

## 10. 维修后遗症与复测

| 问题 | 原因 | 预防 |
|---|---|---|
| 装机后又不亮 | 排线未插紧、座子虚焊 | 装机前蜂鸣档复测 |
| 用几天又坏 | 绿油未固化、补点不牢 | UV 10W 照 3~30 秒，拉力检查 |
| 芯片顶起 | 飞线堆锡太厚 | 飞线贴板、控锡量 |
| 二次短路 | 残锡未清 | 洗板水清洗 + 放大镜 |
| 客户不认 | 无照片/无记录 | 拆前拆后拍照留档 |

## 12. 通用结论

- 掉点 ≠ 死刑：能找到底层走线就能重建。
- 大量「不开机/死机/发热」= 虚焊 → 重植锡。
- 内联座/USB 成败 90% 在温度与焊油。
- 进水损坏 = 腐蚀 + 通电放大，先处理再上电。
- 修完必蜂鸣档逐点复测。
