# 02 开关电源拓扑速查

> 用途：认拓扑 → 找关键点 → 查典型故障。
> 内容：整理自一线硬件工程师的开关电源维修经验；标注「通用公式」的为工程通用知识。

## 1. 六大板块（所有开关电源通用）

| 板块 | 关键元件 | 排查要点 |
|---|---|---|
| ① EMI 滤波 | 保险管、压敏、X 电容、共模电感、Y 电容、放电电阻 | 保险熔断先查后级短路 |
| ② 高压整流滤波 | 整流桥、大电解、NTC、泄放电阻 | 必须有约 310V |
| ③ 高频变压器 | 初级/次级绕组、辅助绕组 | 隔离 + 降压 + 多组次级 |
| ④ 电源管理 | 主控芯片 + 开关管（常在双层板背面） | 启动、驱动、保护 |
| ⑤ 电压电流反馈 | 光耦（95% 以上）+ TL431（基准 2.5V） | 输出偏高/偏低/跳变 |
| ⑥ 低压输出稳压 | 肖特基、滤波电容、滤波电感 | 整流、滤波、带载 |

## 2. 线性 vs 开关

| 项目 | 线性电源 | 开关电源 |
|---|---|---|
| 结构 | 工频变压器 + 整流滤波 + 7805/LM317 | 开关管 + 变压器 + 反馈 |
| 工作状态 | 放大区，持续耗散 | 饱和/截止两态 |
| 效率 | 低 | 80%~95% |
| 体积/重量 | 大 | 小 |
| 纹波/EMI | 纹波小 | 纹波大、EMI 大 |

## 3. 五种基本拓扑对比（正激分单管/双管）

| 拓扑 | 开关管 | 功率范围 | 典型应用 | 典型故障 |
|---|---|---|---|---|
| 反激 | 1 管 | 100W 内，个别 200W | 充电器、路由器、小家电 | 尖峰吸收失效反复炸管；同名端接反 |
| 单管正激 | 1 管 | 100~300W | 工控、适配器 | 复位绕组开路→磁饱和炸管 |
| 双管正激 | 2 管同步 | 几百瓦~上千瓦 | 工控、通讯 | 两管不同步；钳位管坏 |
| 推挽 | 2 管交替 | 几十~几百瓦 | 车载、蓄电池、逆变器 | 偏磁→磁饱和炸管 |
| 半桥 | 2 管交替 + 电容分压 | 几百瓦~1~2kW | 工业电源、基站、电机、D 类功放 | 死区不足直通；分压电容失效中点漂移 |
| 全桥 | 4 管对角成对 | 1kW~几十 kW | UPS、充电桩、新能源车、逆变焊机、光伏 | 死区不足直通；四路时序；轻载 ZVS 失效 |

要点：
- 单管正激需复位绕组；双管正激 D3/D4 把开关管应力钳位到约输入电压。
- 推挽未导通管承受 2 倍输入电压；半桥/全桥为 1 倍输入电压。
- 全桥 ZVS 利用漏感 + 寄生参数在电压≈0 时开通，轻载易失效退回硬开关。

## 4. 反激：完整上电流程（12V 板例）

```
220V → 保险管 → ZNR 压敏 → R52/R53 放电电阻
     → CX1/CX2 → LF 共模电感 → CY1/CY2 → π 滤波
     → BD1 整流桥 → 约 310V ──┬→ 初级绕组 → QE 漏极 D
                              └→ R54、R23 启动电阻 → 芯片 VCC
芯片启动 → 5 脚输出 PWM → D3 → QE 栅极 G
导通：310V+ → 初级 → QE D→S → R6 采样电阻 → 热地
关断：栅极残压 → R9 下拉 → R6 → 地
```

| 关键点 | 元件 | 说明 |
|---|---|---|
| 启动供电 | R54、R23 两颗串联，阻值很大 | 芯片 VCC 建立 |
| 开关管驱动 | 芯片 5 脚 → D3 → G | 无驱动则查 D3/R9 |
| 尖峰吸收 | 肖特基 D1 + C41 + R38~R41 | 反复炸管先查此处 |
| 辅助绕组供电 | D2 整流 → R28/R22 限流 → C4 滤波 | 坏则启动一下就停（打嗝） |
| 过流保护 | R6 压差 → R2 → 光耦 UR → C5 → 芯片 3 脚 | 超限停 5 脚输出 |
| 开关频率 | 1 脚外接 683=68kΩ | 阻值越大频率越低，实测约 65kHz |
| 反馈稳压 | 2 脚 + TL431（2.5V）+ PC817 | 12V→R25/R22→SVR 分压→TL431 |
| 次级输出 | 肖特基整流 + RC 吸收 + 四颗滤波电容 + L2 | 输出 12V |

反馈链路：TL431 导通增强 → 光耦电流增大 → 2 脚电流增大 → 缩短导通 → 输出下降。
多路输出：多组次级绕组分别整流滤波。

## 5. UC3842 反激电源

### 5.1 五大模块

1. 高压输入 EMI 抗干扰
2. 芯片启动供电回路
3. 3842 电源管理
4. 高频开关变压器
5. 次级低压输出稳压

### 5.2 引脚功能

| 脚 | 名称 | 功能 |
|---|---|---|
| 1 | COMP | 误差补偿输出 |
| 2 | VFB | 电压反馈输入 |
| 3 | ISENSE | 电流检测输入 |
| 4 | RT/CT | 振荡定时 |
| 5 | GND | 热地 |
| 6 | OUT | 开关管驱动输出 |
| 7 | VCC | 供电 |
| 8 | VREF | 5V 基准输出 |

### 5.3 关键数据与故障

- 启动电阻：150~220kΩ。
- 启动电容易损坏 → 电源反复重启。
- 高频易损元件如「黄金电容」。
- 过流保护：检测采样电阻电压，超限切断 PWM。
- 稳压：分压采样电阻 + TL431 + 光耦。
- 3842 反激属于硬开关。

关键判据（维修第一步）：

- 7 脚：启动电压 16V，持续工作 10~30V，低于 10V 关闭。
- 8 脚：5V 基准；有无 5V 可快速判芯片好坏。
- 3 脚：电压 >1V 立即锁死 6 脚输出 = 过流保护。
- 4 脚：振荡正常电压约 2V。
- 口诀：7 脚测供电，8 脚测芯片。

## 6. Buck / Boost / Buck-Boost

| 项目 | Buck 降压 | Boost 升压 | Buck-Boost 升降压 |
|---|---|---|---|
| 拓扑 | 开关-电感-二极管-电容 | 电感-开关-二极管-电容 | 调换三元件接法 |
| 关系 | Vout = D·Vin（通用公式） | Vout = Vin/(1−D) | Vout = Vin·D/(1−D)（通用公式） |
| 占空比 | D = Ton/T | D = Ton/T | D = Ton/T |
| 典型 | 12V→5V/3.3V | 1.2V→3V、3.7V→5/9/12/20V | 锂电 4.2~3.0V→稳 3.3V |

要点：
- Buck：开关管每秒几万~十几万次，效率 90% 以上；损耗主要在电感、电容、二极管、MOS；反馈比较实际与目标电压自动调 D。
- Boost：MOS 通→电感储能（二极管反偏，负载靠输出电容）；MOS 断→电感反峰与 Vin 叠加→二极管导通给电容+负载；Vout 节点 = Vin + VL；VL=L·dI/dt；D=0.5 输出 2 倍，D=0.75 输出 4 倍。
- Buck-Boost：Buck 只能降压、Boost 只能升压；普通二极管换肖特基可提高效率、减小体积重量。
- 占空比只看单周期导通占比，与开关频率不是一回事。

## 7. LLC 谐振电源

```
310V ── Q1 ── A 点 ── CR ── LR ── 变压器原边(LM) ── 地
        Q2
A 点接谐振腔：CR 谐振电容 + LR 谐振电感 + LM 励磁电感
```

| 项目 | 要点 |
|---|---|
| 调压方式 | 调频，不调占空比：负载重→频率降，负载轻→频率升 |
| 开关管 | 半桥两管 50% 占空比轮流导通 |
| 谐振腔 | CR + LR + LM；LR 可用独立电感或变压器漏感，LM 为原边励磁电感 |
| 谐振频率 | f = 1 / (2π√(LR·CR)) |
| ZVS | 死区期间谐振电流对开关管寄生电容充放电，把 UDS 拉到≈0 再开通 |
| 死区 | 关键：既防直通，又为下一管创造 ZVS 条件 |
| 优势 | 开关损耗≈0，适合高频高效大功率 |
| 应用 | 快充、氮化镓、充电桩、无人机充电器 |

与硬开关对比：3842 反激导通瞬间仍承受 310V，电压电流重叠产生损耗；LLC 用谐振把重叠错开。

## 8. 拓扑故障定位表

| 现象 | 优先查 |
|---|---|
| 保险熔断 | 压敏、整流桥、大电解、开关管 |
| 310V 正常、无输出 | 启动电阻/电容、辅助绕组、驱动、反馈、次级整流 |
| 反复炸开关管 | 尖峰吸收（D1+C41+R38~R41）、驱动波形、变压器同名端 |
| 启动一下即停（打嗝） | 辅助绕组供电（D2/R28/C4）、启动电容 |
| 输出偏高 | 反馈分压电阻、TL431、光耦 |
| 输出偏低/带载掉压 | 次级肖特基、滤波电容、变压器、限流采样 |
| 空载正常带载保护 | 过流采样 R6、电流检测链路 |
| 半桥/全桥炸管 | 死区、驱动不同步、分压电容 |
| 推挽炸管 | 偏磁、两管不对称 |

## 9. 电压/波形参照

- 整流桥后：310~315V
- 大电解：两颗 330μF 串联 ≈165μF，耐压加倍
- UC3842 频率：1 脚 68kΩ 时实测约 65kHz
- TL431 基准：2.5V
- 次级肖特基压降：0.2~0.4V
- PWM 判读：先看有没有，再看占空比是否随负载变化
