# 00 快速诊断决策树

> 用途：拿到一块故障板，10 分钟内决定「查哪里、怎么测、能不能修」。
> 顺序：安全 → 分流 → 定位 → 验证。数值来自一线维修经验与通用工程资料。
> 配套：04-无图纸修板与故障树.md（板级）、05-故障现象索引.md（症状→案例）。

## 0. 先保命：安全前置（不满足不动手）

| 项目 | 要点 |
|---|---|
| 热地 | 原边地，与市电不隔离，整流桥负极即热地 |
| 压差 | 热地对大地约 110V 到几十伏，接触即麻手 |
| 触电条件 | 一手热地、一手大地/金属桌/水管 → 触电 |
| 唯一安全场景 | 整机经 220V 隔离变压器供电、310V 悬浮时，单手摸热地 |
| 冷地 | 副边地，与市电隔离，可正常测量 |
| 大电解 | 断电后长期存 310V，测前先确认有无电 |
| 放电 | 有电用大电阻跨接放电或专用放电器，禁止直接短路 |
| 首次上电 | 串灯泡限流（补充说明：通用安全实践） |
| 测量纪律 | 先测后拆、单点接地、表笔防打滑，不跨隔离带乱测 |

## 1. 60 秒分流：先回答 5 个问题

1. 220V 进来了吗？保险、压敏、NTC、整流桥是否完好？
2. 310V 有没有？没有 → 查前级；有 → 查后级。
3. 输出有没有？空载、带载各测一次。
4. 有无异常电流、发热、异味、鼓包、打火？
5. 「完全不动」还是「能动但功能异常」？

## 2. 总决策树

```
220V 输入
├─ 保险熔断
│   └→ 压敏、整流桥、大电解、开关管短路链（04 卡）
├─ 保险好、无 310V
│   └→ 整流桥 / 限流 NTC / 铜箔断线
├─ 310V 正常、无输出
│   ├─ 启动电阻、启动电容 → 反复重启「打嗝」
│   ├─ 辅助绕组 D2/R28/C4 供电 → 启动一下就停
│   ├─ 反馈 TL431 + 光耦 → 输出偏高/偏低/跳变
│   ├─ 尖峰吸收 D1+C41+R38~R41 → 反复炸管
│   ├─ 开关管 G 极驱动（D3/R9）→ 无驱动
│   └─ 次级肖特基 / 滤波电容 / L2 → 有驱动无输出
└─ 输出正常但设备异常
    └→ 主板分支：三要素 + 开机电流法（04 卡）
```

反激板实测参照：整流桥后 310V（310~315V），12V 输出经肖特基 + RC 吸收 + 四颗滤波电容 + L2。

## 3. 三个入口判据

### 3.1 看（30 秒扫全板）

- 电解鼓包/漏液/防爆纹裂开
- 电阻烧黑、PCB 烧黄、铜箔起皮
- 引脚虚焊环、焊盘掉点、焊盘发黑
- 进水腐蚀、绿锈、白色结晶
- 排线折断、内联座变形、座子微下沉
- 保险熔断、压敏炸裂、NTC 开裂
- 大功率器件散热片是否缺螺丝/硅脂
- 丝印、测试点、版本号 → 用于反查图纸

### 3.2 测电流（开机电流四态）

| 电流表现 | 判断 | 下一步 |
|---|---|---|
| 未开机就大电流 | 前级输入/充电 IC 一级供电短路 | 松香法、烧机法（低电压限流） |
| 按开机键瞬间大电流 | PMIC 输出端主供电负载短路 | 分段断开、测大电容大电感 |
| 按开机键无电流 | 开关/输入级未通 | 按键通断、充电 IC 输入端电压 |
| 有电流但偏小 | 初始化未完成 | CPU/暂存/存储、测主时钟 |

### 3.3 测电压（三要素）

| 顺序 | 项目 | 异常含义 |
|---|---|---|
| ① | 供电 VCC | 为 0/偏低：前级缺失、保护动作、滤波电容击穿 |
| ② | 复位 RST | 无跳变：复位电路或主控未启动 |
| ③ | 时钟 CLK | 无时钟：晶振、负载电容、主控 |

边界：三要素只能证明基本工作条件，不能证明程序、逻辑、通信。

## 4. 关键阈值速查

| 测点 | 正常参照 |
|---|---|
| 整流桥后 | 310~315V |
| 大电解（两颗 330μF 串联） | 约 165μF，耐压加倍 |
| NTC 冷态/热态 | 5/8/10Ω → 0.5~1Ω |
| 保险管 | 4A/250V（板例） |
| 硅二极管正压 | 0.6~0.7V |
| 肖特基正压 | 0.2~0.4V |
| 蜂鸣档 | 通 0Ω，断无穷大 |
| 无源晶振引脚对地 | 约 VCC/2（3.3V→1.5~1.8V） |
| 晶振两脚直流压差 | 0.1~0.5V，部分 0.8V |
| 32.768kHz 压差 | 仅 0.03~0.08V |
| 有源晶振输出峰峰 | 0.5~2V |
| 热风枪通用 | 320~350℃，不超过 370℃ |

## 5. 开关电源板分支（按六大板块走）

1. EMI：保险管、压敏、X 电容、共模电感、Y 电容、放电电阻
2. 整流滤波：整流桥、大电解、NTC、泄放电阻 → 先确认 310V
3. 高频变压器：绕组通断、匝间（万用表难查）、同名端
4. 电源管理：主控芯片 + 开关管（常在双层板背面）
5. 反馈：光耦（95% 以上电源用）+ TL431（基准 2.5V）
6. 低压输出：肖特基、滤波电容、滤波电感

判据：前三级解决「有没有 310V」，后三级解决「有没有输出」。

## 6. 主板类设备分支（手机/无人机/相机/PAD）

1. 先看进水、摔伤、接口腐蚀
2. 上电看电流 → 按 3.2 四态分流
3. 测三要素 → 按 3.3 逐项
4. 单一功能异常 → 查外设与接口保护；多模块异常 → 回公共供电/主控/总线
5. 修完必须蜂鸣档逐点复测（04 卡）

## 7. 常见误判

- 把「万用表通」当电感好 → 匝间短路测不出
- 电容只看容量不看耐压/极性/类型
- 开关管只看导通，不看 G 极是否悬空
- 保险熔断只换保险，不查后级短路
- 输出跳变只换光耦，不查 TL431 分压电阻
- 主板故障先换芯片，不先测供电/复位/时钟

## 8. 分设备速查（上电时序与首查点）

| 设备 | 上电时序 | 首查点 |
|---|---|---|
| 手机 | 电池→PMIC→多级供电→CPU+时钟→读存储→外设 | 开机电流、PMIC 各路 |
| 无人机 | 电池→电源板→飞控→GPS/图传→云台 | 电源板输出、进水腐蚀 |
| 数码相机 | 电池→电源管理→主控→镜头/传感器 | 电池触点、排线 |
| 对讲机 | 电池→电源→射频/基带 | 功放供电、天线座 |
| PAD/笔记本 | 适配器→充电 IC→多级供电→CPU | 充电 IC 输入、待机电流 |
| 小型 PLC/HMI | 开关电源→主板→IO | 24V/5V/3.3V 供电 |
| 扫地机器人 | 电池→充电管理→主控→电机驱动 | 电池组、驱动管 |

通用口诀：电池/适配器 → 一级供电 → 二级供电 → 主控 → 外设。

## 9. 5 分钟排错清单（照打勾）

- [ ] 断电，目视全板：鼓包、烧黑、进水、掉点
- [ ] 测保险通断；测压敏是否击穿
- [ ] 大电解放电后测容量/短路
- [ ] 上电（串灯泡）测 310V
- [ ] 测输出空载电压、带载电压
- [ ] 摸温度：变压器、开关管、肖特基、L2
- [ ] 听声音：啸叫、打嗝、继电器反复吸合
- [ ] 看波形（有示波器）：PWM 占空比、纹波、时钟
- [ ] 记录：故障现象、实测值、更换件
- [ ] 修完复测：通断、电压、带载 10 分钟

## 10. 停手与送修边界

- 热地未隔离、无隔离变压器：停止带电测量
- 大电解无法确认放电：先放电再动
- 无图纸且 BGA/夹层断线：先报价再动刀
- 进水机未清洗干燥：禁止上电
- 客户不接受风险：只做检测报告
