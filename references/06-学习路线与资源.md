# 06 学习路线与资源

> 用途：零基础到能修板，按顺序学、按清单买、按方向选。
> 核心方法：问题驱动，不做知识囤积；先动手，缺什么补什么。
> 内容：整理自一线硬件工程师的学习路径、工具选型、资料查询与行业职业经验。

## 1. 学习总原则

- 学习不是知识积累，而是问题解决。
- 不要从头啃理论、不要死记硬背；先了解整体轮廓，再跟案例细化。
- 先做一个粗糙的东西 → 碰到真实具体问题 → 针对性找答案、查漏补缺。
- 看懂了 ≠ 学会了：必须动手测、动手焊。
- 先建立全局观：从整体上理解电子电路的底层逻辑，再逐步深入局部。
- 理论三步法：救命理论 → 应对理论 → 基础理论。

## 2. 三阶段路线图

| 阶段 | 目标 | 学什么 | 产出 |
|---|---|---|---|

## 3. 第一阶段：8 元件 + 10 电路

### 3.1 八个必学元件

「掌握」五项标准：知道作用用途、参数怎么看、引脚怎么区分、怎么判断好坏、能不能在板上认出。

| 类别 | 元件 | 特点与用途 |
|---|---|---|
| 被动 3 个 | 电阻 | 限流、分压、取样 |
| | 电容 | 储能、滤波、耦合、去耦；通交流隔直流 |
| | 电感 | 储能、滤波、抗干扰；通直流阻交流 |
| 主动 5 个 | 二极管 | 整流、防反接、续流、稳压、光电 |
| | 三极管 | 小电流控制大电流：放大与开关 |
| | MOS 管 | 电压控制、开关快，电源主力 |
| | 晶闸管 | 触发后自保持，调压/开关/保护 |
| | IGBT | 工业与新能源大功率开关 |

### 3.2 十个基础单元电路

| 序 | 电路 | 作用 / 要点 |
|---|---|---|
| 1 | 整流稳压 + 反激开关电源 | 交流变直流并稳压 |
| 2 | 信号滤波 | 滤掉不需要的频率成分 |
| 3 | 三极管开关 / MOS 开关 | 弱电控制强电 |
| 4 | 共射极放大 | 放大微弱小信号 |
| 5 | 差分放大 | 输入级，抗共模干扰 |
| 6 | 功率放大 | 末级，推动负载 |
| 7 | 选频（带通）放大 | 只放大某一段频率 |
| 8 | RC/LC/晶振振荡 | 产生信号源 |
| 9 | 微分 / 积分 | 处理波形快慢与幅度 |
| 10 | 综合应用 | 上述单元组合成完整功能电路 |

目标：建立电路思维——元件怎么组合、电流怎么被引导。

## 4. 第二阶段：电源与主板

1. 电学基础：电压/电流/电阻/功率/欧姆定律
2. 开关电源六大板块与五大拓扑（02 卡）
3. 反激完整流程 + UC3842（02 卡）
4. Buck/Boost/Buck-Boost/LLC（02 卡）
5. 无图纸七步法 + 开机电流法 + 三要素（04 卡）
6. 焊接工艺 + BGA + 内联座 + 盘圈（03 卡）
7. 故障现象索引与案例（05 卡）

学习顺序建议：先修「能上电但不正常」的板，再修「不开机」的板，最后碰 BGA/进水板。

## 8. 赛道现状（据行业观察）

### 8.1 手机维修

- 2025 年前三季度：全国平均每天约 50 家手机门店倒闭，一年约 1.5 万家，其中 70% 是经营 10 年以上的老店。
- 四块收入：新机销售别碰（平台/直播补贴战）；配件被电商挤压；二手机被以旧换新挤压；维修团购/云连锁（加盟费 8400 元，每月做线上内容、开直播、业绩考核）。
- 结论：只有关闭的门店，没有倒闭的行业；应对 = 适应新玩法、提升服务、多平台 + 线上内容获客。

### 8.2 无人机维修

- 市场分消费级（航拍/娱乐）与商业级（植保、物流、测绘、巡检），龙头大疆、极飞。
- 三大岗位：芯片级维修师傅（适合创业/售后，需求量远小于手机）、装配调试技师（入职有培训还发工资）、持证飞手（UTC/CAAC，岗位有限、常年外派）。
- 保有量：无人机几百万台 vs 手机几亿台，维修需求不是一个量级；「学完接单到手软」是假的。
- 活得好的无人机维修店几乎都是电子维修转型来的，不是小白 3~5 个月速成。

### 8.3 其他赛道

家电、3C 消费电子、工业自动控制、医疗、新能源汽车四类赛道的门槛与隐性成本，需要结合本地市场与自身资源逐项核算，不要只看培训宣传。

## 9. 入行方式与启动顺序

| 路径 | 适合谁 | 真实效果 | 短板 |
|---|---|---|---|
| 技术学校 | 在校生/应届 | 打数模电路理论基础 | 缺实战，毕业不能直接上岗 |
| 短期班 | 有基础、想补案例 | 补常见故障处理技巧 | 零基础跟不上，学完仍不会独立修 |
| 师傅带徒弟 | 有点基础、想攒实操 | 一对一，能当面点拨 | 会做不会讲，理论仍要自己学 |

启动顺序：

1. 小钱试学：买数模基础书 + 免费系统课，验证自己学不学得进去。
2. 确认兴趣再花钱：报线下班或找师傅，补「自学学不到」的故障经验。
3. 带薪学徒：有基础后进实体店当学徒，边学边有薪水，最优解。

时间与避坑：

- 三年入门、五年懂行；一个月顶多学会装配调试，打基础约三个月。
- 「几十节课、两三个月包学会包接单」是演戏；所谓秘籍多是特定机型通病。
- 学完 ≠ 能赚钱：缺的是客户；平台、文案、报价等非技术能力比修机器更重要。
- 报班时机：先练手工（DIY 套件 + 废旧电子产品）+ 补理论（六大核心元件 + 开关电源），到一定程度再报班；报班目的要分清学技术、学经验还是学生意经。

## 10. 技术、生意与创业

- 行业是三分技术、七分生意：技术只解决维修本身，解决不了「客户怎么找到你」。
- 四个观点：①不要过度沉迷技术；②学会借（借人、借势、借物、借技术）；③时间精力是最大成本，能买就买、难修就转；④不要什么都接，品类越杂效率越低。
- 收入差距：同样技术有人月入 3 万、有人 3 千，差在能否让客户认可价值（认知偏差 + 损失厌恶）。
- 创业唯一前提：先一个人独立盈利半年以上，业务忙不过来再租场地、招人。
- 三条红线：不雇闲人、不租贵场地、不买非必要设备；前两年活着最重要。
- 正确顺序：先个人成功再放大 → 先稳定业务再扩张 → 先成不可替代的核心再组团队；先兼职，别裸辞。
