# 01 元器件速查卡

> 用途：看丝印、认封装、量好坏、定替换，一页解决。
> 通用四步：①看丝印/色环 → ②认封装与引脚 → ③万用表测 → ④查手册/替换。
> 内容：整理自一线硬件工程师的元器件识别、测量与代换经验。

## 1. 电阻（R）

### 1.1 类型与选型

| 类型 | 特点 | 典型用途 |
|---|---|---|
| 碳合成 | 耐压好、不易烧 | 高压/浪涌位置 |
| 碳膜 | 最常见、便宜 | 通用 |
| 金属膜 | 精度高、稳定 | 汽车/工控/医疗 |
| 贴片 | 体积小 | 主板/密脚 |
| 水泥 | 大功率 | 电源限流/假负载 |
| 可变 | 三额定：最大阻值/额定电压/额定功率 | 调节/取样 |

规律：尺寸越大功率越大；大个头电阻走大电流。0Ω 电阻 = 保险电阻，检修陌生板优先查。

### 1.2 色环读数

色值：黑 0、棕 1、红 2、橙 3、黄 4、绿 5、蓝 6、紫 7、灰 8、白 9。
误差：金 ±5%、银 ±10%、棕 ±1%、红 ±2%。
尾环：金/棕/银或环距大的一端为尾。

| 环数 | 规则 | 例子 |
|---|---|---|
| 4 环 | 前 2 位有效 + 倍率 + 误差 | 棕黑棕金 = 100Ω ±5% |
| 5 环 | 前 3 位有效 + 倍率 + 误差 | 棕绿黑橙棕 = 150kΩ ±1% |
| 6 环 | 第 6 环为温度系数 | 精密电阻 |

### 1.3 贴片代码

| 代码 | 含义 |
|---|---|
| 3 位 | 前 2 位有效 + 末位零个数，±5%：471=470Ω、473=47k |
| 4 位 | 前 3 位有效 + 末位零个数，±1%：4701=4.7k、3502=35k |
| 带 R | R 为小数点：R003=0.003Ω、R56=0.56Ω、2R20=2.2Ω |
| EIA-96 | 两位数字+字母：23C=16.9k |
| 0 | 0Ω 保险电阻 |

判断：阻值变大/开路 = 坏；阻值变小多因并联通路，需拆下测。

## 2. 电容（C）

### 2.1 分类与替换

| 类型 | 容量/特点 | 替换规则 |
|---|---|---|
| 铝电解 | 几百~几千μF，有极性、防爆纹，寿命约 10~15 年 | 电源端必须电解 |
| 聚合物固态 | 寿命 3~10 倍、成本 3~5 倍、无防爆纹 | 可替同规格电解 |
| 钽 | 横杠端 = 正极，反接会炸 | 按耐压/极性 |
| 瓷片/独石 MLCC | 小容量、无极性、无丝印 | 坏只有短路/开路 |
| 薄膜 CBB/涤纶 | 高压/高频 | 按耐压 |
| 超级电容 | 法拉级 | 按耐压 |
| 穿心/云母/纸介 | 特殊场合 | 原参数 |

铁律：固态可替电解，电解绝不能替固态；耐压只能大不能小。

### 2.2 单位与读数

单位：F / μF / nF / pF，相邻差 3 个零（1μF=1000nF=10⁶pF）。
瓷片/独石：默认 pF。104=100nF=0.1μF、103=10nF、101=100pF、223=22nF、683=68nF、105=1μF、两位数字=pF。
带小数点：默认 μF，0.1=0.1μF；2N2=2.2nF。
钽：104 35=0.1μF/35V、107 6V=100μF/6V、336=33μF。
电解：直接印 16V1500μF、47μF400V。
贴片固态：68 25V=68μF/25V。

贴片电容无丝印：按体积与颜色判容量，体积越大、颜色越深容量越大。

## 3. 电感（L）

- 特性：磁场储能；断电反峰几十~几百倍；抗拒电流突变 = 稳流。
- 「万用表通 ≠ 好」：匝间短路、电感量下降、磁芯破损测不出。
- 磁环：铁氧体磁环抑制共模干扰。
- 替换：电感量、额定电流、直流电阻、封装尺寸四项对齐。

## 4. 二极管（D）

| 类型 | 型号示例 | 关键参数 | 用途 |
|---|---|---|---|
| 整流 | 常见整流管 | 硅管正压 0.6~0.7V | 整流/防反 |
| 肖特基 | SS34、SK34、SB560 | 恢复<10ns、耐压 20~100V、压降 0.2~0.4V | 次级整流 |
| 快恢复 | FR/HER/FU/FS | 约 100ns、1000V+ | 高频整流 |
| TVS | SMAJ/SMBJ/SMF/5.0A、P6KE/1.5KE | 正常几百万欧、浪涌<0.5Ω | 接口防浪涌 |
| 稳压 | Z3V3=3.3V、Z5V1、Z12、BZX55/1N47xx | 必须串限流电阻 | 稳压/钳位 |
| LED | — | 红黄绿 1.8~2.2V、蓝白紫 2.8~3.3V | 指示/背光 |
| 恒流 CRD | — | 约 10V 后恒流 | 恒流源 |

TVS 要点：5V USB 口 2000V 峰值可钳到 10V 内；比压敏/保险电阻快 1000~100 万倍；选型按截止电压。
串管降压：5V−0.7=4.3V，两只→3.6V，可代 3.7V 电池。
桥式整流 = 4 只二极管。

## 5. 三极管（Q）

- 结构：两个 PN 结，E/B/C；NPN 电流 C→E，PNP 电流 E→C。
- 三态：截止 / 饱和 / 放大。
- 三指标：放大倍数 β、耐压、开关频率（低频管不能当高频管）。
- 实测 β 例：68。
- 上拉/下拉电阻防悬空误触发。
- 万用表二极管档：B 对两极单向导通为正常；E-C 也导通 = 击穿。
- 软故障（漏电、软击穿）静态测不出，需代换。

## 6. MOS 管

- 引脚：G-D-S，正面朝上左→右；中间 D 与散热片连通。
- 电压控制；增强型 NMOS 无栅压即断，VGS(th) 2~4V；增强型 PMOS 极性相反；耗尽型默认通。
- S/D 接反时寄生二极管导通，会误判。
- 参数：VGS(th)、ID（留余量，2A 选 ≥3A）、RDS(on)（越小越不热越贵，高频必须小）。
- 栅极上亿欧：悬空 ≠ 关断；拆装前三脚短接放电。
- 好坏判断：红笔接散热片(D)、黑笔接 S 有读数 = PMOS；黑笔接散热片、红笔接 S 有读数 = NMOS；箭头朝内 = NMOS。

## 7. 晶闸管（SCR）

- 引脚：A/K 串主回路，G 触发。
- 触发后撤信号仍导通（两管自锁）。
- 关断三法：断主回路 / 短接 A-K / 电流降到维持电流以下。
- 交流电路中每周期两次过零自动复位。

## 8. IGBT

- 结构：MOS + PNP，引脚 G/C/E。
- 驱动：高 12~15V（少数 10V），低 0~0.5V 或 −5~−9V。
- 能力：耐压 600~6500V、最大电流 3600A+、压降约 2V。
- 100A 对比：1200V MOS 压降约 10V / 功耗约 1000W；IGBT 约 2V / 200W。
- 必看跨导 gfs；三态中线性区最易炸。
- 应用：变频空调 1.5P 约 1100W，每秒几千~上万次开关，省电 30%+；SiC 损耗降 70%+。

## 9. 光耦

- 结构：LED + 光敏接收，输入输出隔离。
- 封装：4~16 脚；4 脚一侧 LED、一侧光敏三极管；6/8 脚多基极/多通道，必须查手册。
- 开关电源 95% 以上用光耦做反馈。
- 异常表现：稳压异常、不开机、输出跳变。

## 10. 霍尔传感器

| 类型 | 特点 |
|---|---|
| 单极性 | 只对一种磁极响应 |
| 锁存双极性 | 需 N/S 交替翻转 |
| 线性 | 输出随磁场线性变化 |
| 全极性 | 对 N/S 都响应 |

实验型号：44E / 41F / 49E / CC6207；多为三脚（电源/地/输出）。
用途：无刷电机换相、测速、电流检测。

## 11. 晶振（X/Y）

- 32.768kHz 常见于 RTC；皮尔斯电路 = 反相器 + Rf + 晶振 + 负载电容 C1/C2（常见 15pF、12.5pF）。
- 无源：两脚不分正负；四脚贴片仅两脚工作。
- 有源：4 脚 VCC/GND/OUT/NC 或 OE（内部上拉，悬空/高正常输出，低停止）；6 脚差分 1=OE、2=NC、3=GND、4=CLK+、5=CLK−、6=VCC，电压 3.3/2.5/1.8V。
- 检测：电阻档两端应无穷大；无源引脚对地约 VCC/2（3.3V→1.5~1.8V）；两脚直流压差 0.1~0.5V（部分 0.8V），32.768k 仅 0.03~0.08V；示波器峰峰 0.5~2V、相位差约 180°；有源可用 1.5V 电池听「哒哒」声。
- 故障现象：灯亮无反应、开机慢、卡画面、死机重启、按键乱跳、触控间歇、花屏、蓝牙/WiFi/串口断续。

## 12. 变压器（T）

- 原理：只能交流、不改变频率；U1/U2 = n1/n2；功率守恒；视在功率 S=U×I（VA）。
- 同名端：黑点表示绕向相位，不是正负极；反激接反会烧件。
- 分类：工频 / 高频开关 / 音频 / 脉冲 / 隔离 / 自耦 / 环形。自耦不隔离，不能当隔离变压器。
- 故障：次级无输出、空载发热、啸叫、初级大电流熔保险、带载下降、漏电麻手。
- 匝间短路万用表测不出，需电感表/匝间测试仪/代换。
- 替换：匝比、频率、隔离耐压、体积引脚、功率余量。

## 13. 保护与安规件（开关电源前级）

| 元件 | 作用 | 判断 |
|---|---|---|
| 保险管 | 过流熔断 | 4A/250V（板例），蜂鸣档通断 |
| 压敏电阻 | 过压钳位 | 220V 规格，市电超约 250V 动作，击穿即短路 |
| NTC | 开机限流 | 冷态 5/8/10Ω，热态 0.5~1Ω |
| X 电容 | 跨火零抗干扰 | 失效多开路/容量降 |
| Y 电容 | 对地抗干扰 | 漏电会麻手 |
| 共模电感 | 抑制共模干扰 | 通断 + 外观 |
| 放电/泄放电阻 | 断电泄放 310V | 四颗串联，阻值变大即失效 |

## 14. 一页速查

- 电阻：色环 4/5 环、贴片 3/4 位、0Ω=保险
- 电容：104=0.1μF、耐压只大不小、固态替电解
- 二极管：硅 0.6~0.7V、肖特基 0.2~0.4V、TVS 钳位
- 三极管：β/耐压/频率；MOS：VGS(th)/ID/RDS(on)
- 晶振：压差 0.1~0.5V、对地 VCC/2
- 变压器：匝比、同名端、隔离耐压

> 型号与参数以器件手册为准；经验值随封装、功率与工艺条件变化。
